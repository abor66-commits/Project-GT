# GCS CRM 電子報 (EDM) 進階操作指南

這份指南將帶您深入了解 GCS CRM 內建的「行銷群發編輯器 (Email Broadcaster)」功能。不論您是想透過簡單的區塊設定快速發信，還是希望由設計師提供原始 HTML 碼進行客製化排版，都能在這裡找到完整的操作步驟。

---

## 1. 介面總覽

進入「行銷工具」後，電子報群發介面主要分為三大區塊：
1. **發送設定區**：選擇受眾（標籤）與填寫信件主旨。
2. **結構化設定側邊欄 (⚙️ EDM Settings)**：快速開啟或關閉信件的固定版塊（頁首、橫幅大圖、按鈕、頁尾）。
3. **主編輯區**：可視化編輯器 (Rich-Text Editor) 與 HTML 原始碼切換區。

---

## 2. 結構化設定 (EDM Settings) 如何使用？

為了讓沒有設計背景的業務與行銷人員也能發出精美的信件，系統提供了一套「積木式」的版塊開關。點擊編輯器右上角的 **「⚙️ EDM 結構設定」** 即可展開側邊欄。

### 🎨 頁首 (Header)
- **品牌名稱 (Title)**：填寫您的品牌或活動名稱，將顯示在信件的最頂端。
- **背景顏色 (Bg Color)**：您可以直接點擊色塊挑選顏色，或輸入品牌的 HEX 色碼（例如：`#FF0000`），讓頁首符合企業識別 (CI)。

### 🖼 橫幅大圖 (Banner)
- 勾選「啟用橫幅圖片」後，將會在信件內容的上方插入一張全寬圖片。
- **圖片網址 (Image URL)**：貼上已經上傳至雲端或官網的圖片網址（開頭必須為 `https://`）。
- **替代文字 (Alt Text)**：若客戶信箱阻擋圖片載入，將顯示此段文字（例如：「2024 秋季新品發表會」），這對 SEO 與無障礙閱讀有極大幫助。

### 🔘 行動呼籲按鈕 (CTA - Call To Action)
- 在信件內容下方加入一個醒目的點擊按鈕，引導客戶轉換。
- **按鈕文字 (Label)**：例如「立即報名」、「查看更多」、「專人聯繫」。
- **跳轉網址 (URL)**：客戶點擊後會前往的目標網頁。
- **按鈕顏色 (Bg Color)**：可自訂按鈕的底色，建議使用高對比色的品牌色以提高點擊率。

### 📄 頁尾 (Footer)
- **頁尾文字 (Footer Text)**：通常用於放置公司的免責聲明、地址、隱私權政策，或是退訂(Unsubscribe)說明。

## 3. 從 HTML 來源建立電子報

如果您有專業的 UI/UX 設計師或外部行銷代理商為您撰寫了完整的 HTML 電子報原始碼，您可以直接在系統中套用。

### 操作步驟：
1. 在「主編輯區」的工具列中，尋找並點擊 **「原始碼 (Source / HTML)」** 按鈕（通常是一個 `< >` 符號）。
2. 這時編輯器會切換為純文字模式。
3. 將原本編輯器內的預設內容清空，並**貼上您的設計師提供的 HTML 原始碼**。
4. 再次點擊 `< >` 按鈕，即可切換回可視化預覽模式，確認排版是否正確顯示。
5. **重要提醒**：若您採用全客製化 HTML，建議將「結構化設定」中的 Header、Banner 與 Footer 關閉，避免系統預設版塊與您的客製化版面重疊。

---

## 4. 範本的儲存與套用 (Template Manager)

如果您設計了一封精美的電子報，下個月還想重複使用，或者想分享給其他業務同事，可以使用範本功能。

### 4.1 儲存為新範本
1. 當信件內容與主旨都編輯完成後，點擊編輯器上方的 **「範本庫」** 按鈕。
2. 選擇「儲存為新範本」。
3. 輸入範本名稱（例如：`2024_展會後跟進信_公版`）。
4. （可選）如果您希望其他同事也能套用這個版型，請勾選「共用 (Shared)」。

### 4.2 套用既有範本
1. 點擊 **「範本庫」** 按鈕，這時會列出所有您建立的，以及其他同事設定為共用的範本。
2. 點擊您要使用的範本，系統會自動覆蓋目前的信件「內容」與「主旨」。
3. 套用後，您依然可以自由修改裡面的文字。

## 5. 個人化動態變數 (Personalization Tags)

大量群發也能營造出「一對一專屬寄送」的尊榮感。在信件主旨或內文中，您可以隨時插入以下兩個標籤：

- `{{contactName}}`：發送時會自動替換為該客戶的主要聯絡人姓名。
- `{{companyName}}`：發送時會自動替換為該客戶的公司名稱。

**實戰範例**：
> **主旨**：`{{contactName}}` 您好，為 `{{companyName}}` 準備的專屬升級方案！
> **內文**：親愛的 `{{contactName}}`，感謝貴公司 `{{companyName}}` 長期以來的支持...

當這封信寄給「王大明（台灣微軟）」與「李小華（台積電）」時，他們會各自收到專屬於自己名字與公司名稱的信件！

---

## 6. 發送前最後檢查：跨載具預覽

強烈建議在點擊「立即發送」之前，先點擊 **「👁️ 預覽郵件」**。
預覽功能不僅會幫您將 `{{contactName}}` 替換為假資料以便測試，更提供了 **手機版 / 桌面版** 的快速切換。

請務必檢查：
1. 圖片在手機版是否會超出螢幕邊緣？
2. 文字大小在手機螢幕上是否容易閱讀？
3. CTA 按鈕是否明顯且容易點擊？

確認無誤後，即可點擊發送，並前往「行銷歷史紀錄」追蹤發送結果！
