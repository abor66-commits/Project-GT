## 1. 系統登入與個人化設定

### 1.1 首次啟用帳號
當系統管理員將您加入系統後，您會收到一封包含 **6 位數一次性密碼 (2FA)** 的邀請信。
1. 點擊信件中的連結前往登入頁面。
2. 輸入您的 Email 與 6 位數安全碼，驗證成功後系統會要求您設定個人專屬密碼。

### 1.2 個人化外觀設定 (Skin Builder)
GCS CRM 提供強大的自定義外觀功能，讓您打造最舒適的工作環境。
- 點擊右上角的「個人頭像」展開選單。
- 選擇 **「外觀設定」**。
- 您可以自由切換多種主題（例如：雅緻大地、深邃黑曜、駭客霓虹等），也可以微調文字粗細、毛玻璃特效與介面圓角。

## 2. 📲 安裝手機 App（PWA 漸進式 Web 應用）

GCS CRM 支援 **PWA（Progressive Web App）** 技術，您可以將 CRM 直接「安裝」到手機桌面，像原生 App 一樣操作，**無需到 App Store 下載**，而且會自動更新至最新版本！

> 📌 **為什麼要安裝 PWA？**
> - 在手機桌面上一點就開，像原生 App 一樣全螢幕操作，不會有瀏覽器的網址列佔空間
> - 支援離線瀏覽已快取的頁面（客戶列表、商機看板等）
> - 即使在訊號較差的環境（如展會、客戶辦公室），仍可查閱先前載入過的客戶資料
> - 搭配手機鏡頭使用 **AI 名片掃描**，拍照建檔一氣呵成！

### 2.1 🍎 iPhone / iPad（iOS Safari）安裝步驟
1. 使用 **Safari** 瀏覽器（⚠️ 必須是 Safari，Chrome 不支援 iOS 上的 PWA 安裝）開啟 CRM 系統網址。
2. 登入系統後，點擊畫面下方的 **「分享」按鈕**（方框加向上箭頭 ↑ 圖示）。
3. 在選單中向下滑動，找到並點擊 **「加入主畫面」（Add to Home Screen）**。
4. 系統會自動帶入名稱「**GCSCRM**」，直接點擊右上角的 **「新增」** 即可。
5. 回到桌面，您會看到 GCS CRM 的圖示已出現，點擊即可全螢幕啟動！

### 2.2 🤖 Android 手機安裝步驟
1. 使用 **Chrome** 瀏覽器開啟 CRM 系統網址並登入。
2. Chrome 通常會在畫面底部自動彈出 **「新增至主畫面」** 的橫幅提示，直接點擊 **「安裝」** 即可。
3. 若未出現提示，請點擊 Chrome 右上角的 **「⋮ 選單」**，選擇 **「安裝應用程式」** 或 **「新增至主畫面」**。
4. 安裝完成後，桌面上會出現「**GCSCRM**」App 圖示，點擊即可以 App 模式全螢幕開啟。

### 2.3 🖥️ 桌面電腦（Chrome / Edge）安裝步驟
1. 使用 Chrome 或 Edge 開啟 CRM 系統網址。
2. 在網址列右側會出現一個 **「安裝」圖示**（↓ 加框），點擊後選擇 **「安裝」**。
3. CRM 會以獨立視窗開啟，並在您的應用程式列表中建立捷徑。

### 2.4 💡 PWA 使用提示
- **自動更新**：PWA 會在每次開啟時自動在背景檢查更新，您永遠使用最新版本。
- **離線支援**：已瀏覽過的頁面（客戶列表、商機看板）在斷網時仍可讀取快取內容，但新增/修改資料等操作需要網路連線。
- **通知**：若您的瀏覽器允許通知權限，未來系統將可推送即時提醒。
- **解除安裝**：若要移除，在手機上長按圖示選擇「刪除」；桌面版可在 Chrome 的 `chrome://apps` 頁面中移除。

## 3. 客戶管理與 AI 名片辨識

### 3.1 📸 AI 智能名片掃描（強烈推薦）
在外跑業務或參加研討會拿到大量名片？再也不需要手動打字！GCS CRM 整合了 **Google Gemini AI 多模態視覺辨識**技術，只需一張照片即可自動建檔。

#### 📱 手機掃描完整操作流程
1. **開啟 CRM**：在手機上點擊桌面的「GCSCRM」App 圖示（建議先完成 [§2 PWA 安裝](#2--安裝手機-app-pwa-漸進式-web-應用)，體驗更佳）。
2. **進入客戶管理**：點擊左側選單的「客戶管理」頁面。
3. **點擊掃描按鈕**：頁面上方會看到 **「📷 掃描名片」** 按鈕，點擊後會彈出 AI 掃描視窗。
4. **拍照或上傳**：
   - 🔹 **即時拍照**：點擊畫面中央的 📷 圖示區域，系統會自動呼叫手機的後置鏡頭，將鏡頭對準名片拍照。
   - 🔹 **上傳圖檔**：也可從手機相簿選擇先前拍攝的名片照片（支援 JPG、PNG、HEIC 等格式）。
5. **AI 即時解析**：拍照完成後，畫面會顯示 **「AI 辨識中...」** 旋轉動畫，通常僅需 **2–3 秒** 即可完成解析。
6. **智能比對結果**：
   - ✅ **已有客戶自動匹配**：AI 會根據 Email 的網域名稱（如 `@microsoft.com`）自動比對系統中已存在的公司。若比對成功，會顯示綠色提示「✅ 已匹配到現有公司：XXX」，新聯絡人將自動歸入該公司名下。
   - 🆕 **全新客戶自動建立**：若為全新公司，系統會提示「將建立新公司」，AI 會同時建立公司與聯絡人資料。
7. **目視確認**：系統會顯示解析後的資料卡片，包含：`姓名`、`職稱`、`公司`、`Email`、`電話`，請快速目視核對。
8. **一鍵儲存**：確認無誤後點擊 **「確認儲存」** 按鈕，客戶資料即自動建立完成！若有誤，可點擊 **「重新掃描」** 重拍。

#### 📸 拍攝要領（提升辨識準確率）
| 要領 | 說明 |
|------|------|
| **光線充足** | 在明亮環境下拍攝，避免強烈反光或陰影遮蓋文字 |
| **對齊放平** | 將名片平放在桌面上，鏡頭正對名片，避免傾斜歪曲 |
| **完整入鏡** | 確保名片四個角落都在畫面內，不要裁切到邊緣資訊 |
| **對焦清晰** | 等手機對焦完成（文字清晰可辨）再按快門 |
| **避免遮擋** | 手指不要遮住名片上的文字或 Logo |

> 💡 **小技巧**：如果一次拿到大量名片，可以先全部拍照存到相簿，之後再逐一上傳辨識，省去逐張對焦的時間！

#### ⚠️ 常見問題排除
| 問題 | 解決方法 |
|------|----------|
| 拍照後出現「辨識超時」 | 可能是網路訊號不穩，請切換至 Wi-Fi 環境後重試 |
| AI 辨識的文字不正確 | 請確保照片清晰且光線充足；對於設計感過強的名片（花紋背景、藝術字體），AI 辨識率可能稍低，建議手動微調 |
| 手機沒有跳出拍照畫面 | 請確認瀏覽器（或 PWA）已授予「相機」權限。iOS 請至「設定 → Safari → 相機」允許；Android 請至「設定 → 應用程式 → Chrome → 權限 → 相機」允許 |
| 上傳照片沒有反應 | 請確認照片格式為 JPG、PNG 或 HEIC，且檔案大小不超過 10 MB |

### 3.2 手動新增與管理客戶
- 點擊「新增客戶」，輸入基本資料、所屬產業與平台。
- 在客戶詳情頁面，您可以隨時修改客戶資訊、新增商機，或是為客戶貼上行銷標籤。

## 4. 精準標籤管理與分眾

標籤是行銷分眾與業務篩選的關鍵基礎。透過賦予客戶特定的標籤，可以極大化行銷精準度。

### 4.1 貼標籤
- 進入任何一家客戶的詳細頁面，在標籤區塊點擊新增。
- 您可以選擇既有標籤（如：`VIP`、`AWS-Target`、`2026-TechSummit`），或請管理員建立新標籤。

### 4.2 透過標籤篩選與分眾
- 在「客戶管理」列表，使用上方的 **「標籤篩選器 (Tag Filter)」**。
- 選擇特定標籤，系統會立刻列出所有符合該標籤的客戶名單。
- 這些名單將成為後續發送電子報 (EDM) 的精準受眾！

## 5. 商機看板與銷售漏斗追蹤

幫助業務主管與專員隨時掌握每一筆案子的進度與總金額。

### 5.1 建立商機與追蹤行銷來源 (ROI)
1. 在左側選單進入 **「商機管理」** 或直接在客戶詳情頁點擊新增商機。
2. 填寫預估金額、負責業務，以及最重要的 **「商機來源」**（如：LinkedIn、研討會）與 **「行銷活動代號」**。
   *(此舉能幫助行銷團隊精準追蹤每一場活動帶來的實際成交效益！)*

### 5.2 視覺化拖拉看板 (Kanban)
- 進入「商機管理」的看板模式。
- 您會看到商機依據狀態分為：`初步接觸` ➔ `需求確認` ➔ `提案/報價` ➔ `讓價` 等階段。
- 業務只需使用滑鼠**直接拖拉**商機卡片到下一個階段，系統即會自動更新狀態並重新計算各階段的總預估金額。

## 6. 自建電子報 (EDM) 群發系統

行銷團隊不需再把名單匯出至第三方系統，直接在 CRM 內完成精準寄送。

### 6.1 選定受眾與撰寫信件
1. 進入左側選單的 **「行銷工具」**。
2. 在「發送名單」區塊，選擇您稍早整理好的**標籤**（例如：發送給所有 `2026-TechSummit` 的客戶）。
3. 使用內建的可視化編輯器撰寫信件，您可以隨意設定粗體、顏色或插入連結。

### 6.2 💡 聯絡人專屬變數 (Personalization)
讓每封信看起來都像是為客戶專屬客製的！
在信件主旨或內文中輸入以下變數：
- `{{contactName}}`：發送時會自動替換為該客戶的聯絡人姓名。
- `{{companyName}}`：發送時會自動替換為該客戶的公司名稱。
*(範例：你好 `{{contactName}}`，感謝參加活動！)*

### 6.3 👁️ 跨載具預覽與發送
1. 信件編輯完成後，點擊 **「預覽郵件」**。
2. 系統會立刻模擬帶入真實的客戶姓名，讓您確認變數是否正確運作。
3. 在預覽視窗上方，您可以自由切換 **桌面版 (Desktop)** 與 **手機版 (Mobile)**，確保信件在手機上閱讀時排版不會跑掉。
4. 預覽無誤後，即可點擊發送！發送完畢後，您可以在「行銷歷史紀錄」中查看每一封信件的成功/失敗狀態。
